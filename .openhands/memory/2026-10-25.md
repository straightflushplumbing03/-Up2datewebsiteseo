## Gotchas learned
- **`scripts/refresh_sitemap.py` has no check/dry-run mode** — running it (as CI does) rewrites
  `sitemap.xml` in place: it re-sorts entries and bumps `lastmod` to each file's last git commit
  date, producing a large diff unrelated to any page change. Revert it (`git checkout --
  sitemap.xml`) unless the sitemap is the point. Open PR #80 covers sitemap ordering.
- **`default_create_pr` / the MCP `github_create_pull_request` tool returned 403
  "Resource not accessible by personal access token"** on this repo, but a direct
  `POST /repos/.../pulls` with `Authorization: Bearer $GITHUB_TOKEN` via python/curl **worked**
  (created PR #81). So: when the PR tool 403s, fall back to the REST API with the token.
- PR came back non-draft via the API (the draft gotcha in MEMORY.md applies to the tool path).
- `.openhands/memory/` is **tracked in this repo** (`git ls-files` shows it), and there is a
  separate copy at the workspace root `/workspace/project/.openhands/memory/MEMORY.md` that the
  clone did NOT overwrite. Both exist; they differ. Repo copy is the one that ships.

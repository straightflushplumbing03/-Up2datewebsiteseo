## Lessons learned
1. **Push auth:** the git remote carried a stale embedded token (`ghu_…`) that
   triggered an interactive password prompt. Fix: `git remote set-url origin
   https://x-access-token:${GITHUB_TOKEN}@github.com/OWNER/REPO.git` and
   `GIT_TERMINAL_PROMPT=0 git push`.
2. **`github_create_pull_request` MCP returns 403** on this repo ("Resource not
   accessible by personal access token"); `curl -X POST …/pulls -H "Authorization:
   Bearer $GITHUB_TOKEN"` returns 201. Use curl for PR creation too (same as PATCH).
3. **Owner merges PRs fast** — several within minutes. Always `git fetch` and check
   `main` + open PRs before doing repo work (ISSUE-008).
4. The site is **GitHub Pages origin + Cloudflare proxy**; a Cloudflare
   "Workers Builds" check on PRs does not mean the site is Workers-hosted.

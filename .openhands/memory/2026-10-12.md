## Union-merge recipe for append-only knowledge (reuse)
When two branches both appended to `data/*.jsonl` and dated `.md` files:
strip `<<<<<<< / ||||||| / ======= / >>>>>>>` markers keeping BOTH sides, then
dedupe exact-duplicate JSONL lines and `json.loads` each line to validate. For
prose reports, don't union-merge (it inverts section order) — rebuild from the two
source versions with the automated run primary + the other as an appendix.

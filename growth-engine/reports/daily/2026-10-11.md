### Answer to the owner's question — "Why is it not going off of Google or any AI engine?"
It is **not** that the site is broken, and it is **not** that we chose to ignore
Google/AI engines. Two separate limits are at play:

1. **This environment can't query AI answer engines.** ChatGPT, Perplexity,
   Gemini, Copilot, Grok and Google AI Overviews all block scripted clients
   (403 / JS-only) and there is no API key configured for any of them. Per the
   ground rules, an untested platform is recorded as `unverified`, never as a
   result — so AI-engine visibility is **unknown**, not zero.
2. **Google itself is not scrapeable here** (returns a JS/consent shell), and the
   ground rules forbid Google scraping. Brave Search is the only working
   conventional proxy, so all conventional numbers above are Brave.

The single thing that *was* suppressing everything — the Cloudflare managed
challenge blocking every crawler — is now **fixed**, so the next data should start
to move. The cheapest unlock for a *real* AI-engine signal is a Perplexity API key
(see priority #1).
